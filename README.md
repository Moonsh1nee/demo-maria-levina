# Мария Левина — демо-сайт психолога

Демонстрационный личный сайт семейного психолога. Специалист, отзывы, цены и адреса вымышлены, сайт сделан студией Akimov Web как пример работы и закрыт от индексации.

## Что умеет

- Главная страница: о специалисте, запросы, формат и стоимость встреч, заметки, вопросы и ответы.
- Короткий тест на усталость из шести вопросов. Результат запоминается в браузере и не заменяет консультацию.
- Форма записи с проверкой полей. Заявка никуда не отправляется и сохраняется только в браузере посетителя.
- Блог из трёх примеров статей.
- Светлая и тёмная темы, адаптивная вёрстка, спокойная анимация «дыхания» вокруг портрета (отключается при prefers-reduced-motion).

## Стек

Next.js (App Router, статический экспорт), TypeScript, Tailwind CSS v4, React Hook Form и Zod, lucide-react.
